# Post Call Quality Analysis

This project analyzes post-call data using various analytics and machine learning models.

## Getting Started

Follow these steps to set up and run the application after cloning the repository.

### 1. Clone the Repository
```sh
git clone https://github.com/<your-username>/Post_Call_Quality_Analysis.git
cd Post_Call_Quality_Analysis
```

### 2. Create and Activate a Virtual Environment (Recommended)
#### On Windows (PowerShell):
```sh
python -m venv venv
.\venv\Scripts\Activate.ps1
```
#### On macOS/Linux:
```sh
python3 -m venv venv
source venv/bin/activate
```

### 3. Install Dependencies
```sh
pip install -r requirements.txt
```

### 4. Run the Application
Navigate to the `app` directory and run `app.py`:
```sh
cd app
python app.py
```

## Notes
- Ensure you have Python 3.8 or higher installed.
- If you are using large model files, Git LFS may be required. Install it from [Git LFS](https://git-lfs.github.com/) if needed.
- For any issues, check the code comments or raise an issue in the repository.
